SUNHAVEN BAY is an open-world crime game built with three.js. Explore a sunlit coastal city, take jobs, steal cars, and evade the police.

## Controls

- **WASD** — walk or drive
- **E** — enter a car
- **F** — steal a car
- **M** — missions
- **Wanted stars** — show your police alert level

## Features

- Open city with traffic and pedestrians
- Police wanted system with escalating pursuit
- Story missions and a save system

## Run

```sh
node serve.ts
```

Then open [http://localhost:8080](http://localhost:8080).

## Tech

Built with vendored three.js. No build step or install is required; the static game files are in `game/`.
